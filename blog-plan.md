## Architecture when publishing begins

- `/blog` is a server-rendered index with topic filters implemented as crawlable links only when they lead to useful index pages.
- `/blog/[slug]` uses a typed content source, unique metadata, Article + Breadcrumb schema, author/reviewer disclosure, real published/modified dates, and related articles.
- Category pages remain noindex until they contain enough distinct articles and a useful introduction.
- XML sitemap includes only published canonical articles. Drafts and scheduled content never return 200 on public routes.
- Each article receives an explicit primary cluster so automated related links cannot create cross-topic noise.
